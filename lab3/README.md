# Лабораторная работа №3. Ollama и RAG через MCP

## 1. CPU-модель в Kubernetes

Ollama `0.40.17`, `qwen2.5:0.5b`, GGUF Q4_K_M. Веса входят в отдельный образ.
Развёртывание и контрольная генерация в Kubernetes — в работе.

## 2. База знаний и MCP

36 записей, 35 ID, 6 разделов, 12 подразделов. SQLite FTS5, индексация секциями.
`search_docs`, `get_doc`, `list_sections` через Streamable HTTP. Bearer-токен и проверка Origin.
Локальный MCP-контракт проверен; поиск: К01–К08 и К01 с фильтром — 9/9.

Корпус загружается отдельным ConfigMap; исходный JSON и закрытые фрагменты в Git и публичные образы не входят.

## 3. RAG и маршруты

`llm7.io → Ollama CPU → search_only`. Один снимок контекста, фильтры версий/статусов/пути, серверные ссылки на секции.
`local_only` и приватный режим обходят облако.

**Реальный llm7.io не проверен:** кабинет требует пополнения для создания API-ключа. Подготовлен отдельный синтетический имитатор.

## 4. Портал

Поиск, дерево редакций, ответ с источниками, маршрут, причина и число вызовов. Диагностика 429, quota, 503, timeout и отказа обеих моделей.

## 5. Проверки

Проверки ответов CPU-модели и маршрутов в Kubernetes выполняются. Фактические отчёты будут добавлены в этот PR.
